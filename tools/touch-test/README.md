# touch-test

터치스크린이 없는 PC 에서 몽독 상단바·독에 **손가락 입력**(탭, 길게 누르기, 끌기)을 흉내 내는 시험 도구.
`InitializeTouchInjection` + `InjectTouchInput` 으로 진짜 터치처럼 윈도우에 넣으므로 WPF 의 터치→마우스 승격,
윈도우 "누르고 있기 = 손 떼면 오른쪽 클릭" 제스처, 몽독의 터치 전용 분기(`DockWindow.Touch.cs`, 상단바 길게 누르기)까지 그대로 탄다.

앱 코드와는 무관하고 `mongdock.sln` 에도 들어 있지 않다. 외부 NuGet 없음.

> 주의: 입력이 **실제 화면 전체**에 들어간다. 다른 사람이 PC 를 쓰는 중에는 실행하지 말고, 좌표는 몽독 상단바·독 위로만.
> 먼저 `--dry-run` 으로 좌표를 확인할 것. 손가락 위치를 보여 주는 윈도우 기본 터치 표시가 잠깐 뜬다.

## 빌드

```
dotnet build tools/touch-test/touch-test.csproj -c Release
```

결과: `tools/touch-test/bin/Release/net8.0-windows/touch-test.exe`

## 사용법

```
touch-test info                                  주 모니터 크기·배율, 상단바·독 예시 좌표
touch-test tap  X Y                              탭 (60ms)
touch-test hold X Y [ms=800]                     길게 누르기
touch-test drag X1 Y1 X2 Y2 [ms=600] [먼저누름ms=0]
```

- 좌표는 **물리 픽셀**(주 모니터 왼쪽 위 기준). `--dip` 를 붙이면 DIP 로 보고 주 모니터 배율을 곱한다.
- 상대 좌표: `r-40` = 오른쪽 끝에서 40, `b-40` = 아래 끝에서 40, `c` / `c+30` / `c-30` = 가운데 기준.
- 옵션: `--wait 초`(보내기 전 대기, 기본 3), `--repeat N`, `--dry-run`(보내지 않고 계산된 좌표만 출력).
- 누르는 동안 16ms 마다 UPDATE 를 보낸다 (안 보내면 윈도우가 접촉이 끊긴 것으로 봄).

## 시험 예 (몽독 기본 배치: 상단바 26, 독 아이콘 52)

| 확인할 것 | 명령 | 기대 |
|---|---|---|
| 독 아이콘 탭 = 실행/활성화 | `touch-test tap c b-40 --dip` | 그 앱이 앞으로 옴, 독이 확대된 채 남지 않음 |
| 독 아이콘 길게 누르기 = 메뉴 | `touch-test hold c b-40 900 --dip` | 손 뗄 때 독 메뉴만 뜨고 앱은 실행되지 않음 |
| 독 아이콘 끌기 = 순서 바꾸기 | `touch-test drag c b-40 c+120 b-40 600 --dip` | 마우스 끌기와 같음 |
| 상단바 아이콘 탭 = 패널 | `touch-test tap r-60 13 --dip` (아이콘 위치에 맞게) | 패널이 한 번 열림 |
| 상단바 아이콘 길게 누르기 | `touch-test hold r-120 13 700 --dip` | 0.4초 뒤 순서 바꾸기 모드, 움직이지 않고 떼면 오른쪽 클릭 메뉴 한 번 |
| 상단바 아이콘 순서 바꾸기 | `touch-test drag r-200 13 r-300 13 500 500 --dip` | 0.5초 누른 뒤 왼쪽으로 끌려 순서가 바뀜 |
| 패널 행(링크) 탭 | 패널을 연 뒤 링크 좌표로 `tap` | 마우스 클릭과 같음 |

정확한 아이콘 좌표는 화면 캡처에서 재거나 `info` 의 예시에서 조정한다.

## 한계

- 손가락 하나만 (핀치·두 손가락 스크롤 없음).
- 펜(호버가 있는 입력)은 흉내 내지 않음.
- 원격 데스크톱/StarDesk 같은 원격 세션에서는 주입이 막히거나 원격 쪽 화면에 들어가지 않을 수 있다.
- 몽독의 `TouchSupport` 는 `GetSystemMetrics(SM_MAXIMUMTOUCHES) > 0` 일 때만 행 높이를 키운다. `info` 가 0 이면
  행 높이 변화는 이 도구로 시험되지 않는다 (입력 처리만 시험됨).
