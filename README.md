# MyDock

윈도우 11용 맥 스타일 독 + 상단바. C# / WPF / .NET 8, 외부 패키지 없음.

원격 데스크톱(맥 → StarDesk) 환경에서 Ctrl+Win+화살표, 한/영 키 같은 단축키가 넘어가지 않는 문제를 **클릭만으로** 해결하는 것이 주 목적.

## 기능

### 독
- 화면 왼쪽 / 오른쪽 / 아래 / 위 어디든 배치. 독의 빈 곳을 끌어서 다른 가장자리로 옮기거나 가장자리를 따라 위치 조정
- AppBar 로 등록해서 최대화 창이 독을 가리지 않음 (설정으로 끌 수 있음)
- 핀 고정 앱 + 실행 중 앱, 클릭 시 실행 / 전환 / 최소화
- 알림은 바운스 없이 아이콘의 작은 빨간 점으로만 표시
- 스토어 앱은 AUMID 로 저장 → 앱 업데이트 후에도 핀이 풀리지 않음
- 커스텀 아이콘은 `%APPDATA%\MyDock\icons\` 로 복사해서 보관
- 오른쪽 클릭 메뉴로 고정 / 제거 / 순서 변경 / 아이콘 변경 / 위치 변경

### 상단바
- 가상 데스크톱 ◀ ▶ + 버튼
- 한/영 표시 + 클릭 전환 (상단바가 포커스를 가져가지 않아서 현재 앱에 적용됨)
- 검색, 빠른 설정, 알림 센터 버튼
- 현재 앱 이름, 시계

## 빌드 / 실행

```bash
dotnet build -c Release
```

```bash
src/MyDock/bin/Release/net8.0-windows/MyDock.exe
```

## 설정

`%APPDATA%\MyDock\settings.json` — 저장하면 바로 반영됨. 위치, 크기, 색, 투명도, 핀 목록, 상단바 버튼 표시 여부 등.

첫 실행 시 MyDockFinder(`C:\Tweaks\My Dock\MyDock\ico.ini`)가 있으면 핀 목록을 가져옴.

로그: `%APPDATA%\MyDock\logs\mydock.log`
