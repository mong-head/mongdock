# MyDock

윈도우 11용 맥 스타일 독 + 상단바. C# / WPF / .NET 8, 외부 패키지 없음.

원격 데스크톱(맥 → 원격 접속 앱) 환경에서는 Ctrl+Win+화살표, 한/영, Win+A 같은 단축키가 넘어가지 않는다. 그런 기능을 **클릭만으로** 쓰는 것이 주 목적이다. 독과 상단바는 클릭해도 포커스를 가져가지 않아서, 한/영 전환 같은 동작이 지금 쓰던 앱에 그대로 적용된다.

## 기능

### 독
- 화면 왼쪽 / 오른쪽 / 아래 / 위 어디든 배치. 독의 빈 곳을 끌어서 다른 가장자리로 옮기거나 가장자리를 따라 위치 조정
- 동작 모드
  - **자동 숨김**(기본): 화면 가장자리에 마우스를 대면 나타남
  - **항상 표시**: 창 위에 겹쳐 보임
  - **공간 차지**: 독의 기본 두께만큼 화면을 예약해서 최대화 창이 독을 가리지 않음
- 반투명 블러 배경, 라이트 / 다크 / 시스템 테마
- 맥처럼 커서 주변 아이콘이 함께 커지는 물결 확대
- 모든 아이콘을 macOS 아이콘 규격(같은 크기·여백·둥근 사각형·그림자)으로 맞춰서 표시
- 핀 고정 앱 + 실행 중 앱, 클릭 시 실행 / 전환 / 최소화
- 알림은 바운스 없이 아이콘의 작은 빨간 점으로만 표시
- 스토어 앱은 AUMID 로 저장 → 앱 업데이트 후에도 핀이 풀리지 않음
- 커스텀 아이콘은 `%APPDATA%\MyDock\icons\` 로 복사해서 보관
- 오른쪽 클릭 메뉴: 고정 / 제거 / 순서 / 아이콘 변경 / 위치 / 동작 모드 / 테마 / 로그인 시 자동 실행

### 상단바
- 로고 메뉴(시작 메뉴, 작업 보기, 독 위치, 상단바 색, 설정, 종료)
- 가상 데스크톱 ◀ ▶ + 버튼, 현재 앱 이름
- 네트워크 속도, 블루투스, Wi-Fi, 볼륨 — 클릭하면 볼륨 슬라이더·블루투스 토글 패널
- 검색, 빠른 설정, 알림 센터 버튼
- 한/영 표시 + 클릭 전환
- 시계
- 색 모드
  - **투명**(기본): 바탕화면이 비치고, 글자색은 배경 밝기에 따라 자동
  - **앱 색에 맞춤**: 바로 아래 창 색으로 칠함
  - **블러**
  - **고정 색**

## 빌드 / 실행

.NET 8 SDK 필요.

```bash
dotnet build -c Release
```

```bash
src/MyDock/bin/Release/net8.0-windows10.0.19041.0/MyDock.exe
```

종료는 상단바 로고 메뉴 → "MyDock 종료".

## 설정

`%APPDATA%\MyDock\settings.json` — 저장하면 바로 반영된다. 독 위치·모드·크기·테마·색, 상단바 색 모드·표시 항목, 핀 목록 등. 색 문자열이 `""` 이면 테마 기본값.

첫 실행 시 MyDockFinder 의 `ico.ini` 가 있으면 핀 목록을 가져온다.

로그: `%APPDATA%\MyDock\logs\mydock.log`
