# 여러 환경 점검 (터치 · 저사양 · 세로/고배율 모니터 · 회사 PC)

마지막 점검: 2026-10-08 (v0.3.5 기준). "확인"은 코드 검토 + 숫자 하네스 수준이고, 실기기 확인이 필요한 항목은 따로 적었다.

## 1. 터치스크린 (2-in-1)

| 항목 | 동작 | 근거 / 비고 |
|---|---|---|
| 독 아이콘·상단바 버튼·메뉴·패널 행 누르기 | WPF 터치→마우스 승격으로 클릭 그대로 | 별도 처리 없음 |
| 독 아이콘 길게 누르기 | 윈도우 "누르고 있기" 제스처 → 손 떼면 오른쪽 클릭 → 독 메뉴 | 0.6초 이상 누른 터치는 실행(왼쪽 클릭)으로 치지 않음 (`DockWindow.Touch.cs`) |
| 독 아이콘 끌기 | 손가락을 움직이면 순서 바꾸기 (마우스와 같음) | |
| 독 호버 확대 | 터치 이동은 확대하지 않음, 손 떼면 확대·이름표 해제 | 손가락 아래 아이콘이 밀려나지 않게 |
| 독 자동 숨김 | 터치를 뗀 뒤엔 커서가 독 위에 남아도 바깥으로 보고 숨김 | 진짜 마우스가 2 DIP 넘게 움직이면 다시 정상 판정 |
| 상단바 오른쪽 아이콘 길게 누르기 | 0.4초 → 순서 바꾸기. **움직이지 않고 떼면 오른쪽 클릭** (트레이 아이콘 = 앱 메뉴, 나머지 = 상단바 메뉴) | 이 구역만 시스템 "누르고 있기" 제스처를 끔 (`Stylus.IsPressAndHoldEnabled=False`) — 켜 두면 누름이 늦게 승격돼 0.4초 판정이 안 되고 메뉴가 겹쳐 뜸 |
| ⌃ 카드 트레이 아이콘 길게 누르기 | 시스템 제스처 → 오른쪽 클릭(앱 메뉴), 왼쪽 클릭은 보내지 않음 | `TrayIconButton` |
| 메뉴 행 높이 | 터치 장치(`GetSystemMetrics(SM_MAXIMUMTOUCHES) > 0`)면 26 → 30 | `MenuRowMinHeight` 리소스 |
| 상태 패널 행(링크·기기 목록) | 터치 장치면 위아래 패딩 +2씩 (행 +4) | 상단바 버튼 크기는 그대로 |

**실기기 확인 필요**: 실제 터치 장치가 없어 동작 확인 못 함. 특히 ① 독 아이콘 길게 누르기에서 메뉴만 뜨고 앱이 실행되지 않는지 ② 상단바 아이콘 길게 누른 뒤 떼면 메뉴가 한 번만 뜨는지 ③ 탭 직후 독이 확대된 채 남지 않는지 ④ 펜(호버 있음)은 마우스처럼 확대되는지.

## 2. 저사양 PC — 가벼운 모드

측정 (이 PC, 설치본 v0.3.5, 평상시 · 마우스 거의 안 움직임, 60초 간격 2회):

| 항목 | 값 |
|---|---|
| CPU 시간 증가 | 0.56초 / 60초 → 코어 1개 기준 0.94%, 전체(12 스레드) 0.08% |
| Working Set | 약 216 MB |
| Private Memory | 약 124 MB |

UI 쪽 상시 타이머 정리:

| 타이머 | 전 | 후 |
|---|---|---|
| 상단바 시계 | 1초마다 | 초를 표시하지 않는 형식이면 다음 분 경계에 한 번 (시간 변경·절전 해제 시 즉시) |
| 상단바 한/영·앱 이름 | 300ms | 300ms (가벼운 모드 600ms), 전체 화면으로 숨으면 멈춤 |
| 상단바 Auto 색 샘플링 | 500ms | 500ms (가벼운 모드 1초), 전체 화면으로 숨으면 멈춤 |
| 독 자동 숨김 트리거 | 60ms, 매 틱 모니터 조회 | 60ms (가벼운 모드 120ms), 모니터 조회는 8틱마다, 전체 화면 동안 멈춤 |

**가벼운 모드** (설정 → 일반, 설정 모델에 `PerformanceMode` 가 있을 때 표시): 애니메이션 끔(시스템 "애니메이션 효과" 끔과 별개로), 독 블러 → 반투명 단색, 상단바 블러 모드 → 같은 틴트의 반투명 단색, 독 호버 확대 1.0·물결 끔, 독 자동 숨김 슬라이드 없이 바로, 위 확인 주기 2배.

백엔드 타이머(이 작업 범위 밖, 제안): 트레이 맨 위 유지 100ms(`TrayIconService` TimerRaise), 알림 DB 4초 폴링, 창 추적 1.5초 폴링, 전체 화면 확인 1초, 배경화면 2초, 네트워크 속도 1초, 와이파이 5초, 배터리 30초.

## 3. 세로 모니터 · 특이 배율

숫자 하네스(`DockFit` / `TopBarFit` 를 그대로 링크한 콘솔)로 계산한 결과. 독은 아이콘 52·간격 5·아이콘 25개 + 구분선 2개, 상단바는 트레이 8개·속도·데스크톱 켬 기준.

| 화면 | DIP 폭 | 독 아이콘 (자동 축소) | 상단바 오른쪽 접기 |
|---|---|---|---|
| 1920 가로 @100% | 1920 | 52 | 없음 |
| 1920 가로 @150% | 1280 | 43 | 없음 |
| 1920 가로 @175% | 1097 | 36 | 없음 |
| 1920 가로 @200% | 960 | 30 | 없음 (앱 이름 최대 166) |
| 1920 가로 @225% | 853 | 26 | 트레이 4개 ⌃ 로 |
| 1080 세로 @100% | 1080 | 35 | 없음 |
| 1080 세로 @125% | 864 | 26 | 트레이 4개 ⌃ 로 |
| 1080 세로 @150% | 720 | 21 | 트레이 전부 + 속도 |
| 1080 세로 @175% | 617 | 17 | 트레이 전부 + 속도 + 데스크톱 |
| 1080 세로 @200% | 540 | 16, 간격 3 | 위와 같음, 앱 이름 말줄임 |
| 1080 세로 @225% | 480 | 16, 간격 1 | 위와 같음, 앱 이름 48 (몇 DIP 겹칠 수 있음) |

- **독**: 패널이 독 방향 길이(작업 영역/예약 영역)보다 길면 아이콘을 줄이고, 최소 16에서도 넘치면 간격도 줄임. 설정값은 그대로, 앱이 줄거나 화면이 넓어지면 되돌아감 (`DockWindow.Fit.cs`).
- **상단바**: 오른쪽이 왼쪽(로고 + 앱 이름 120)을 덮으면 ① 트레이를 뒤쪽부터 ⌃ 로 ② 네트워크 속도 ③ 데스크톱 묶음 순서로 접고, 넓어지면 반대로 펼침(8 DIP 여유로 깜빡임 방지). 그래도 모자라면 앱 이름 말줄임. 앱 메뉴 제목 » 묶음은 기존대로.
- **Spotlight**: 카드 폭 680 → 모니터 폭 − 24 이하(최소 280). 경로 부제목 폭도 같이 줄어듦.
- **상태 패널**(최대 352)·알림 배너(344)·코치마크(300): 가장 좁은 480 DIP 에서도 들어감, 위치는 기존 코드가 화면 안으로 고정.
- **설정 창**: 기본 780×620, 최소 640×420 → 주 모니터 작업 영역 − 24 를 넘지 않게. 480 DIP 에서는 사이드바 200 + 내용이 좁아 일부 행이 잘릴 수 있음.

**실기기 확인 필요**: 실제 세로 모니터·175/200/225% 에서 독 축소 후 Reserve 두께·자동 숨김 트리거, 상단바 접기 후 ⌃ 카드에 접힌 아이콘이 맨 앞에 보이는지, 폭이 바뀌는 순간 깜빡임.

## 4. 회사 PC

| 환경 | 현재 처리 | 결과 |
|---|---|---|
| 프록시 (시스템 설정·PAC) | 모든 `HttpClient`(업데이트 API·다운로드, 캘린더 구독, 메뉴 규칙)가 기본 `UseProxy=true` + `HttpClient.DefaultProxy`(윈도우 시스템 프록시) 사용 | 일반 프록시 OK |
| 인증 프록시 (NTLM/Kerberos) | 프록시 자격 증명 미설정 → 407 로 실패 (실패는 조용히 로그 + 재시도) | **백엔드 수정 필요**: 시작 시 `HttpClient.DefaultProxy.Credentials = CredentialCache.DefaultCredentials;` 한 줄 (모든 클라이언트에 적용) |
| 윈도우 검색 서비스 꺼짐 | Spotlight 파일 검색 건너뜀 | 기존 처리 OK |
| 작업 표시줄 설정 정책으로 막힘 | `ABM_SETSTATE` 결과를 쓰지 않음 → 실패해도 예외 없음, 작업 표시줄이 그대로 보일 뿐 | OK (안내 없음) |
| 그룹 정책으로 Run 키 무시 | 등록·조회 모두 try/catch + 로그. 정책(`DisableCurrentUserRun` 등)으로 무시되면 토글은 켜져 보이지만 자동 실행 안 됨 | 개선 제안: `IStartupService.IsBlockedByPolicy` 로 설정 창에 안내 |
| AppLocker 로 %LOCALAPPDATA%·Temp 실행 막힘 | 업데이트 설치 실행 실패 → "설치 프로그램을 실행하지 못했어요." | 개선 제안: Win32 오류 1260(정책 차단)이면 "회사 정책으로 막혀 있어요 — 릴리스 페이지에서 받아 IT 담당자에게" 로 구분 |
| 알림 DB 접근 거부 | 직접 읽기 실패 → 사본 모드 → 실패는 한 번만 로그, 알림 기능만 조용히 빠짐 | OK (4초마다 사본 시도는 계속 — 백오프 제안) |
| 개인 정보 설정으로 위치·카메라 레지스트리 제한 | 이 버전은 위치·카메라 레지스트리를 읽지 않음 (카메라·마이크 표시는 별도 작업) | 해당 작업에서 try/catch 확인 필요 |
